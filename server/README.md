# Серверная часть приложения "Картина по пикселям"

## Структура проекта

```
server/
├── server.py                 # Основной Flask сервер
├── requirements.txt          # Зависимости Python
├── data/                     # Модуль для работы с данными
│   ├── __init__.py
│   ├── access_codes_manager.py  # Менеджер кодов доступа
│   └── access_codes.json     # Файл с кодами доступа
├── excel_generator/          # Модуль для генерации Excel файлов
│   ├── __init__.py
│   ├── excel_generator.py    # Генератор Excel файлов
│   └── *.xlsx               # Сгенерированные Excel файлы
└── README.md                # Этот файл
```

## Модули

### data.access_codes_manager
Менеджер для работы с кодами доступа:
- Генерация уникальных кодов
- Проверка кодов
- Сохранение/загрузка данных
- Статистика использования

### excel_generator.excel_generator
Генератор Excel файлов:
- Создание файлов с кодами доступа
- Создание файлов со статистикой
- Управление файлами

## API Endpoints

### Коды доступа

#### `POST /api/admin/generate-codes`
Генерирует 500 новых кодов доступа и создает Excel файл.

**Ответ:**
```json
{
  "success": true,
  "message": "Сгенерировано 500 кодов доступа",
  "excel_file": "access_codes_20250705_184709.xlsx",
  "total_codes": 500
}
```

#### `GET /api/admin/download-codes/<filename>`
Скачивает Excel файл с кодами.

#### `POST /api/verify-code`
Проверяет код доступа.

**Запрос:**
```json
{
  "code": "1234-5678-9012"
}
```

**Ответ:**
```json
{
  "valid": true,
  "message": "Код действителен"
}
```

#### `GET /api/admin/stats`
Получает статистику по кодам доступа.

**Ответ:**
```json
{
  "total_codes": 500,
  "used_codes": 10,
  "unused_codes": 490,
  "generated_at": "2025-07-05T18:47:09"
}
```

#### `POST /api/admin/generate-stats-excel`
Создает Excel файл со статистикой.

#### `GET /api/admin/list-excel-files`
Возвращает список всех Excel файлов.

### Обработка изображений

#### `POST /api/convert-pixels`
Конвертирует изображение в картину по номерам (цветная).

#### `POST /api/convert-pixels-bw`
Конвертирует изображение в картину по номерам (черно-белая).

#### `POST /api/convert-pixels-sepia`
Конвертирует изображение в картину по номерам (сепия).

#### `POST /api/convert-pixels-horizontal`
Конвертирует изображение в горизонтальную картину по номерам.

#### `POST /api/convert-pixels-horizontal-bw`
Конвертирует изображение в горизонтальную черно-белую картину по номерам.

#### `POST /api/convert-pixels-horizontal-sepia`
Конвертирует изображение в горизонтальную сепийную картину по номерам.

## Запуск сервера

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите сервер:
```bash
python server.py
```

Сервер будет доступен по адресу `http://localhost:5000`

## Формат кодов доступа

Коды генерируются в формате `XXXX-XXXX-XXXX`, где X - цифра от 0 до 9.

Пример: `1234-5678-9012`

## Безопасность

- Коды хешируются для безопасного хранения
- Каждый код может быть использован только один раз
- Все операции с кодами логируются
