# Картина по пикселям

Веб-приложение для создания картин по номерам из любых фотографий с системой кодов доступа.

## Структура проекта

```
paint-by-number/
├── frontend/                 # React фронтенд
│   ├── src/
│   │   ├── components/       # React компоненты
│   │   ├── config.js         # Конфигурация API
│   │   └── ...
│   ├── package.json
│   └── ...
├── server/                   # Python Flask сервер
│   ├── server.py            # Основной сервер
│   ├── requirements.txt     # Python зависимости
│   ├── data/                # Модуль для работы с данными
│   │   ├── access_codes_manager.py
│   │   └── access_codes.json
│   ├── excel_generator/     # Модуль для Excel файлов
│   │   └── excel_generator.py
│   └── README.md
├── images/                   # Примеры изображений
└── README.md                # Этот файл
```

## Возможности

### Для пользователей

- Загрузка изображений (JPG, PNG)
- Автоматическое создание картин по номерам
- Три режима: цветной, черно-белый, сепия
- Два формата: вертикальный и горизонтальный
- Система кодов доступа для ограничения доступа

### Для администраторов

- Генерация кодов доступа (500 штук за раз)
- Создание Excel файлов с кодами
- Статистика использования кодов
- Управление доступом

## Быстрый старт

### 1. Запуск сервера

```bash
cd server
pip install -r requirements.txt
python server.py
```

Сервер будет доступен по адресу `http://localhost:5000`

### 2. Запуск фронтенда

```bash
cd frontend
npm install
npm run dev
```

Фронтенд будет доступен по адресу `http://localhost:5173`

### 3. Администрирование

1. Перейдите на `/admin` для доступа к панели администратора
2. Сгенерируйте коды доступа
3. Скачайте Excel файл с кодами
4. Распространите коды пользователям

### 4. Использование

1. Пользователи переходят на главную страницу
2. Вводят код доступа
3. Загружают изображение
4. Получают картину по номерам

## API Endpoints

### Административные

- `POST /api/admin/generate-codes` - Генерация кодов
- `GET /api/admin/stats` - Статистика
- `GET /api/admin/download-codes/<filename>` - Скачивание Excel
- `POST /api/admin/generate-stats-excel` - Excel со статистикой

### Пользовательские

- `POST /api/verify-code` - Проверка кода доступа
- `POST /api/convert-pixels*` - Конвертация изображений
